# Holden Econ Lab

Personal repo for economics research, public writing and career work by
Holden Spitznagle (econ student, personal trainer, building Morph).

One question ties it together: **why don't people do what's good for their
health, and what actually changes that?** It sits where behavioral and health
economics meet.

| Folder | What's in it |
|---|---|
| `research/` | One folder per paper idea |
| `content/` | *The Economics of Getting Healthy* series |
| `career/` | Résumé notes, applications, target roles |
| `reading/` | Notes on papers |
| `log/` | Dated session notes |

Full background, standards and current status: [`CLAUDE.md`](CLAUDE.md).

This repo is separate from Morph. Research here uses public data and public
literature only.
